Install Riskwell for Jira

This page forwards you to the Atlassian installation page for Riskwell for Jira (a Forge app by SKILLMERC (Pty) Ltd) in a few seconds. Riskwell keeps a risk register in each Jira project, with inherent and residual scores, a heat map, review reminders and a Rovo agent.

Open the installation page

You need a Jira Cloud site where you are an admin. After installing, open any Jira project, choose Risk register in the project tab bar (it may sit under More) and click Add risk. The Rovo agent needs a site with Rovo. Everything else works without it.
