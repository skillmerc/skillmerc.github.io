How to get an alert when part of a web page changes in Firefox

2 min readChangekeep

Reloading a page to see if a notice, a list or a date has changed wastes time. Changekeep checks the part you care about and tells you when it changes.

With Changekeep

  1. Install Changekeep from Firefox Add-ons. It needs Firefox 142 or later, on a computer.
  2. Open the page and click the Changekeep button. Point at the part you want and click it.
  3. Check the value in the panel and click "Save watch". The first time you watch a site, the watch list asks you to allow Changekeep to check that site.
  4. When the part changes, you get a notification and a count on the button. The change view shows "Was" and "Now" with the changed words marked.

Calm by design

  • It compares only the part you picked, not the whole page.
  • Extra spaces, invisible characters and times like "5 minutes ago" do not count as changes.
  • If the part is missing from the page, you see a problem, not a change.
  • Not a real change? Click "Ignore changes like this".

Free

10 watches, each checked as often as every 30 minutes, an alert on any change. Pro is coming soon and is not on sale yet.

Limits

  • Checks run only while your browser is open.
  • Alerts are browser notifications. There are no email or text message alerts.
  • If the page draws the part with scripts after it loads, a background check cannot see it. Changekeep tells you when you pick that part.
