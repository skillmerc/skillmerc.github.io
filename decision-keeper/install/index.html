Install Decision Keeper for Confluence

This page forwards you to the Atlassian installation page for Decision Keeper for Confluence (a Forge app by SKILLMERC (Pty) Ltd) in a few seconds.

Open the installation page

You need a Confluence Cloud site where you are an admin. Approve the four permissions. After installing, open Apps, then Decision Register, and choose Add sample decisions. A site with Rovo is needed for the agent. Everything else works without it.
