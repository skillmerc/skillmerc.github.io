Redeem a deal code for List & Table Scraper Pro

If you bought List & Table Scraper Pro through a deal marketplace, you received a one-time code. This page turns that code into a lifetime Pro license key. The total is USD 0.00 and you are not asked for a card.

The next screen is the checkout of Freemius, our licensing provider. It shows the Pro lifetime plan with your code applied (100% off) and a button "Upgrade for Free". The phone field there is optional, leave it empty.

Steps

  1. Install the add-on: List & Table Scraper for Firefox. It is on Firefox today.
  2. Fill in your name, email and deal code above and click "Redeem code".
  3. On the Freemius screen, check that the total is USD 0.00 and click "Upgrade for Free". Freemius emails your license key to the address you entered.
  4. Open the add-on's "Pro license" page (the add-on's options, or the "I have a key" link in the panel), paste the key and click "Activate". The plan changes to Pro.

Good to know

  • There is no account or password. Your license key is your access, so keep the email.
  • One code gives one lifetime Pro license for one browser. To move it, click "Deactivate on this browser" first, then activate on the other browser.
  • Pro reads up to 500 pages per run and saves a recipe per website. The free version reads up to 3 pages per run. Exports to CSV, Excel and JSON are free either way.
  • Each code works once. Codes stay valid for at least 60 days after you buy.
  • If the Freemius screen shows a total other than USD 0.00 or asks for a card, the code was not accepted (mistyped or already used). Do not pay. Go back, check the code, or email us.
  • Refunds are handled by the marketplace where you bought the code. When a code is refunded, its license is cancelled.
  • Stuck? Email kyle@skillmerc.com with your code and we will sort it out.
