How to scrape a list from multiple pages into Excel or CSV without code

Search results, store categories, job boards and directories usually show 20 or 30 items per page with a Next link at the bottom. Copying page by page is slow and easy to get wrong. Here is what works without writing code.

What Excel and Google Sheets can do on their own

  • Google Sheets IMPORTHTML reads one HTML table or list from one address. For several pages you need one formula per page, and it only works when the page address changes in a predictable way (for example ?page=2) and the data is a real HTML table or list.
  • Excel Data, then From Web (Power Query) can load tables from a web address. Combining many pages means editing the query, which is doable but fiddly.
  • Neither one sees lists built from cards (product tiles, job cards, directory entries), and neither can click a Next button that loads results without changing the address.

Collect all pages with a browser add-on

List & Table Scraper is a free Firefox add-on we make. It works on the page as you see it, so it handles card layouts and Next buttons too.

  1. Open the first page of results and click the add-on's toolbar button. It outlines the block of repeated items and shows a preview. If it picked the wrong block, click Try another.
  2. Click Locate Next button, then click the site's own Next link or button.
  3. Set Max pages (default 20) and the Delay between pages (1 to 10 seconds), then click Crawl pages.
  4. It collects page after page until there is no Next, or until your page limit, and drops duplicate rows.
  5. Download CSV, Excel (.xlsx) or JSON, or copy and paste into Google Sheets.

When Next is a normal link, the next pages are loaded in the background from the same site, so the page you are on stays where it is. When Next is a button that updates the page in place, the add-on clicks it and waits for the new rows. For pages that load more items as you scroll, use Infinite scroll instead.

Limits worth knowing

  • It reads what the page has loaded. If a site builds its list with JavaScript after a link-based Next, the background load may not find the list, and the panel tells you when that happens.
  • Use a delay of a few seconds and a sensible page limit so you do not hammer the site, and respect each website's terms of use.
