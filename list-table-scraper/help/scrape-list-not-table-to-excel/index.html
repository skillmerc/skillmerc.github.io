How to scrape product cards or search results (not a table) into Excel or Google Sheets

6 min readList & Table Scraper

Short answer: product cards, search results and directory entries are usually repeated blocks, not table tags, so table tools find nothing or put each card's text in one cell. For a short list, copy and paste plus one formula, or Excel's Add Table Using Examples, works with nothing to install; for long or messy lists, a browser add-on that finds the repeated blocks, such as List & Table Scraper, gives you one row per card with its links.

Why table tools miss card layouts

On most shops, search pages and directories, each item is a block that holds a title, a price, a link and an image. There is no table behind it.

  • Google Sheets IMPORTHTML only reads table tags and ul or ol lists from the page source. If the cards sit inside a list, "list" returns each card's text in one cell, not split into columns. If they do not, you get nothing.
  • Copy and paste puts every line of every card on its own row, and the link addresses are usually lost.
  • Excel Data, From Web shows the tables it detects. A grid of cards often shows up as no table at all.

Free ways that need no install

1. Copy and paste, then fold the lines into rows

Good for one or two pages where every card has the same lines.

  1. Select the cards on the page, copy, and paste into column A of a new sheet. In Google Sheets use Ctrl+Shift+V (Cmd+Shift+V on a Mac) to paste text only.
  2. Count how many rows one card takes, for example 4 (name, price, rating, stock).
  3. In an empty cell type =WRAPROWS(A1:A400, 4), with A400 changed to the last row you pasted. Each group of 4 lines becomes one row. WRAPROWS works in Google Sheets and in Excel for Microsoft 365.

Limits: it breaks as soon as one card has an extra or missing line, such as a sale price or "Out of stock". The links behind the titles are lost.

2. Excel: From Web, then Add Table Using Examples

Excel's web connector can learn a pattern from a few examples.

  1. In Excel open Data, choose From Web, paste the page address and click OK.
  2. In the Navigator window click Add Table Using Examples (bottom left).
  3. Type the first two or three values of a column, for example two product names. Excel suggests matching values as you type and fills in the rest. Add a column for prices the same way.
  4. Click OK, select the new custom table and click Load.

Limits: Microsoft says the feature comes with a Microsoft 365 subscription. Excel downloads the page itself, so pages that need you to be signed in usually do not work, and some sites block these requests. You also need one query per page of results.

3. Google Sheets IMPORTXML, when the data is in the page source

IMPORTXML takes an XPath, so it can pick parts of each card:

  • =IMPORTXML("https://example.com/search?q=lamp", "//h3") returns the text of every h3 heading.
  • =IMPORTXML("https://example.com/search?q=lamp", "//h3/a/@href") returns the links inside them.

Find the right tag by right clicking a product name and choosing Inspect. Put one formula per column side by side.

Limits: like IMPORTHTML, it reads the page source that Google's servers download, not the page your browser shows. Cards built by JavaScript are not there (see why IMPORTHTML and IMPORTXML come back empty). If one card lacks a field, that column shifts by one row and the rows no longer line up.

4. Your browser's console, if you are happy to paste one line of code

The console sees the page exactly as you do, signed in and after scripts have run. Chrome and Firefox both have a copy() helper that puts text on the clipboard.

  1. Press F12 (Cmd+Option+I on a Mac) and open the Console tab.
  2. Paste this line and press Enter. It copies each product heading and its link, separated by a tab:
copy([...document.querySelectorAll("h3 a")].map(a => a.innerText + "\t" + a.href).join("\n"))
  1. Paste into a sheet. The tab splits it into two columns.

Change h3 a to match the site: right click a product name, choose Inspect, and look at the tag around it. Your browser may warn you about pasting code and ask you to type "allow pasting" first. Only paste code you understand.

Limits: you need a selector that matches every card, and each extra column means more code.

With a browser add-on

List & Table Scraper is an add-on we make for Firefox and Chrome. It finds repeated blocks by their structure, so cards, search results and list items work the same way as tables.

  1. Open the page as you normally would (signed in, filters set) and click the add-on's toolbar button. It outlines the block it picked on the page and shows a preview with one row per card.
  2. If it picked the wrong block, click Try another.
  3. Each column holds text, link addresses or image addresses from the cards. Rename a column by typing in its header, or remove it with the x.
  4. Click Copy and paste into Google Sheets or Excel, or download CSV, Excel (.xlsx) or JSON.

Results split over several pages? Click Locate Next button, click the site's Next, then Crawl pages (see scraping a list from multiple pages). Pages that load more as you scroll use Infinite scroll (see infinite scroll pages). The free version reads up to 3 pages per run; Pro reads up to 500. Export is free either way.

Limits worth knowing

  • The add-on reads what the page has loaded. It cannot see items the site has not shown yet.
  • It cannot read browser pages such as about: pages or the add-on stores.
  • Scraped data stays in your browser. The free version needs no account, and the add-on has no server.
  • Please respect each website's terms of use, and take only what you need.

Frequently asked questions

Can IMPORTHTML scrape product cards?

Only when the cards are inside a ul or ol list in the page source, and then each card's whole text lands in one cell. IMPORTXML is the better formula for cards, because an XPath can pick the name, price and link separately.

How do I keep the links when I copy a list from a website?

Plain copy and paste usually keeps the text and drops the addresses. IMPORTXML with /@href at the end of the XPath returns the links, the console line above copies them next to each title, and List & Table Scraper puts link addresses in their own column.

Why are my columns out of line after scraping?

One card is missing a field, or has an extra one, so every value after it moves up a row. This happens with WRAPROWS and with IMPORTXML formulas placed side by side, and you have to fix the gap by hand. List & Table Scraper reads each card as a whole, so a missing field becomes an empty cell in that card's row.

Is it allowed to scrape a website into a spreadsheet?

It depends on the site's terms of use and the law where you live, so read the terms first. This is not legal advice. Keep a few seconds between pages so you do not load the site heavily.
