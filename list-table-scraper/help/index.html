List & Table Scraper: guides

Practical guides for getting tables and lists from websites into a spreadsheet. The add-on works in Firefox and Chrome.

  • How to export a Wikipedia table to Excel, Google Sheets or CSV (3 free ways)
    Three free ways to get a table from Wikipedia into a spreadsheet: copy and paste, Google Sheets IMPORTHTML, or a browser add-on that also keeps the article links. When to use each one.
  • How to scrape a list from multiple pages into Excel or CSV without code
    Search results, directories and product listings are split across pages. How to collect every page into one spreadsheet without writing code, what Excel and Google Sheets can and cannot do, and how to stay polite to the website.
  • How to scrape an infinite scroll page into Excel or CSV
    Pages that load more items as you scroll defeat copy and paste, IMPORTHTML and Power Query. Why that happens, the manual workarounds, and how to collect the list into a spreadsheet with a browser add-on for Firefox or Chrome.
  • IMPORTHTML not working in Google Sheets? Why it fails and how to get the table anyway
    IMPORTHTML returns "Imported content is empty", "Could not fetch url" or the wrong table. The usual causes (JavaScript tables, logins, blocked requests, wrong index) and a free way to get the data into Sheets anyway.
  • How to scrape product cards or search results (not a table) into Excel or Google Sheets
    Product grids, search results and directory cards are not HTML tables, so table tools miss them or squash them into one column. Free ways that need no install, what each one cannot do, and a browser add-on that turns each card into a row.
  • How to scrape a table that spans several pages into Excel or Google Sheets
    A table that shows 10 or 25 rows at a time with a Next button. How to check whether all rows are already in the page, how to stack pages with IMPORTHTML or Power Query when the page number is in the address, and what to do when it is not.
  • How to copy a web table to Excel and keep the columns
    Pasting a web table into Excel often puts everything in one column or shifts cells. Here is how to get each column into its own Excel column, with the header names, in Chrome or Firefox.
  • How to export product cards from a shop page to CSV
    Shop pages show products as cards, not tables, so copy and paste fails. Here is how to export each product card as one CSV row, with name, price, link and image address, in Chrome or Firefox.
  • How to export search results from a website to a spreadsheet
    Get the results of a search on a website (titles, links, snippets) into Excel, Google Sheets or CSV, one row per result, across several result pages.
  • How to scrape a directory listing into Excel
    Turn a business or member directory on a web page into an Excel sheet: one row per listing, with names, links and addresses in their own columns, without writing selectors.
  • How to export job listings from a job board to Excel or CSV
    Save the jobs from a job board search into Excel or CSV, one row per job with title, company and link, so you can sort and track them.
  • How to convert a table on a web page to JSON
    Download any table or list on a web page as a JSON file with one object per row, using the column names you choose. No code, in Chrome or Firefox.
  • How to extract the links and image URLs from a list on a web page
    Get the link address and image address of every item in a list or grid on a web page into a spreadsheet column, next to the item's text.
  • Web table numbers stored as text in Excel: how to get real numbers
    Numbers copied from a web page often land in Excel as text, so SUM gives 0 and sorting is wrong. Here is a quick fix, and a way to export the table with real numbers, prices and dates.
  • CSV from a web page shows broken accents in Excel: how to fix it
    Accented letters like é or ü turn into odd characters when you open a CSV in Excel. Why it happens, how to fix an existing file, and how to export a web table as a CSV that opens cleanly.
