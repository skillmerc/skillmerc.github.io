How to copy a table from a website into Google Sheets

2 min readList & Table Scraper

Short answer: select the table on the page, copy it, and paste it into cell A1 in Google Sheets. For a plain HTML table the cells usually land in the right columns. When they do not, or the "table" is really a list of boxes, use one of the two ways below.

Way 1: the IMPORTHTML formula

In a cell, type =IMPORTHTML("https://example.com/page", "table", 1) with the page address. The last number picks the first, second or third table on the page.

It only sees tables in the page's HTML. It fails on pages that build the table with scripts, on pages behind a login, and on lists that are not tables. See IMPORTHTML not working for the errors and what they mean.

Way 2: List & Table Scraper

  1. Install the extension and open the page with the table.
  2. Click the List & Table Scraper button in the toolbar. It outlines the table or list it found and shows a preview of the rows and columns.
  3. Wrong block? Click "Try another".
  4. Rename a column by typing in its header, or remove it with the x.
  5. Click "Copy", then click cell A1 in Google Sheets and paste. Each column lands in its own Sheets column.

It reads the page you have open, so it works on pages you are signed in to and on lists that are not tables. A table split over several pages can be collected with "Crawl pages": 3 pages per run on the free version, up to 500 with Pro.

Limits

  • It reads what the page has loaded. A list built by scripts after a link-based Next page may not be found; the panel tells you when that happens.
  • Browser settings pages and the extension store cannot be read.
  • Respect each site's terms of use.
