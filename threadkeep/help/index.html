Threadkeep: guides

Practical guides for saving AI chats: the free ways first, then Threadkeep.

  • How to export a DeepSeek chat to PDF, Word or Markdown (free ways and a Firefox or Chrome add-on)
    DeepSeek has no button that saves one chat as a PDF, Word or Markdown file. What its own "Export data" and share link give you, where print and copy and paste fall short, and the steps with the Threadkeep add-on for Firefox and Chrome.
  • DeepSeek "Length limit reached": how to continue a long chat in a new chat
    When a DeepSeek chat hits its length limit, DeepSeek sends you to a new chat. What the message says, how to carry the old chat across by hand, and how the Threadkeep add-on for Firefox and Chrome turns it into paste-ready parts.
  • How to export a ChatGPT conversation to PDF or Word (free ways and a browser add-on)
    ChatGPT has no button that saves one conversation as a PDF or Word file. What its own "Export data" and shared links give you, how to print a chat to PDF, and the steps with the Threadkeep add-on for Firefox and Chrome.
  • How to save a Claude chat as Markdown or PDF (free ways and a browser add-on)
    Claude has no button that saves one chat as a Markdown or PDF file. What its own "Export data" and shared chats give you, how to print a chat to PDF, and the steps with the Threadkeep add-on for Firefox and Chrome.
  • How to save Gemini chats: Export to Docs, Google Takeout, PDF and Markdown
    The ways to save a Gemini chat, checked on Google's help pages: Export to Docs for one response, Google Takeout for all your Gemini activity, a public link, print to PDF, and the Threadkeep add-on for Firefox and Chrome.
  • How to keep a searchable library of your ChatGPT, Claude, Gemini and DeepSeek chats
    Keep the AI chats you want in one place you can search. The free ways (each app's data export, a folder of Markdown files) and their limits, then the Threadkeep library in Firefox: save, search, folders, tags, backup.
  • How to export a DeepSeek chat with the reasoning (thinking) included or left out
    Save a DeepSeek conversation as Markdown, text, JSON, PDF or Word, and choose whether the reasoning section goes into the file. Maths keeps its LaTeX.
  • How to export a NotebookLM (Gemini Notebook) chat to Markdown, PDF or Word
    Save the chat from a Google notebook (Gemini Notebook, formerly NotebookLM) as Markdown, text, JSON, PDF or Word with the Threadkeep extension for Chrome and Firefox.
  • How to export an AI chat to JSON (ChatGPT, Claude, Gemini, DeepSeek)
    Save one AI conversation as a JSON file with the title, the source address and each message's role and text, for scripts, datasets or your own archive.
  • How to export a ChatGPT chat to Markdown with code blocks and tables
    Save one ChatGPT conversation as a Markdown file that keeps code blocks, tables, lists and links, with the Threadkeep extension for Chrome and Firefox.
