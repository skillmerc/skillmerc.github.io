Install Closewell for Jira

This page forwards you to the Atlassian installation page for Closewell for Jira (a Forge app by SKILLMERC (Pty) Ltd) in a few seconds.

Open the installation page

You need a Jira Cloud site where you are an admin. After installing, open any Jira project, choose Month-end close in the project tab bar (it may sit under More) and click Use sample company. No accounting login is needed.
