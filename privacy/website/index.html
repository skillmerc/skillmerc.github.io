Privacy: this website

skillmerc.com does not use cookies and does not try to work out who you are. It counts visits, so we can see which pages help people and which do not.

What is recorded

  • The address of the page you opened and, if you followed a link, the site you came from.
  • The width of your browser window, your browser's language and time zone, and a rough device type (phone, tablet or computer) with the browser family.
  • Which buttons and links you pressed, for example "Get it free", how far down the page you scrolled and how long it was open.
  • Words typed into the site's own search box, and the answer the "Find my tool" form gave.

What is never recorded

  • Your name, email address or IP address.
  • Anything that follows you to another website or from one day to the next.

To tell one visitor's page views apart within a single day, our server makes a one-way code from the IP address, the browser name and a secret that changes every day. The IP address itself is not stored, and yesterday's codes cannot be matched to today's.

How to switch it off

If your browser sends "Do Not Track" or "Global Privacy Control", nothing is recorded at all.

Forms

If you sign up for email updates, Privacy: email updates says what we keep and how to unsubscribe. Any other email address you leave in a form is used for that purpose only.

Where it is kept

The counts are kept by SKILLMERC (Pty) Ltd on our own database (Supabase) behind our own service (Railway) for up to 13 months, then deleted. They are not sold or shared.

GLYPHWORKS (our game on itch.io)

Our browser game GLYPHWORKS can count plays and minutes played, using the same server as this site. It sends something only when the version on itch.io has play counting built in and counting is switched on. It sends at most three short messages per visit:

  • "start" on your first key press or tap, saying whether your save is new or returning.
  • "edition" if you reach the first Edition during that visit.
  • "session" with your active time, once, the first time the page is hidden or closed. Time counts only while the tab is visible and you pressed a key or tapped in the last 60 seconds.

For each message our server stores: the time it arrived, the message name, the page name /games/glyphworks, a version number, a random id made when the game loads (it ties one visit's messages together; the game keeps it in memory only, so your next visit gets a new one), new or returning (start only), the active time (session only), the device type (phone, tablet or computer), the browser family, the operating system family and the daily visitor code described above. It does not store your IP address, the full browser name, your itch.io name or anything you type. Rows are deleted after 400 days.

The game sets no cookies. It sends nothing if your browser sends "Do Not Track" or "Global Privacy Control", or if you switch counting off. To switch it off, press "counting on" at the bottom of the game so it reads "counting off". Your browser remembers that choice as the word "off", not as an id.
