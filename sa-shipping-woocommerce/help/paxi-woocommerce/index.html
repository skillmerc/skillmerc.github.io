PAXI on WooCommerce: letting customers pick a PAXI point

PAXI (the PEP parcel service) is often the cheapest way to send a small parcel across South Africa, and many customers already use it. The problem for WooCommerce stores: in October 2026 PAXI's own business FAQ answered "Does the PAXI location map work on Shopify or WooCommerce sites?" with "Not at the moment". Their API needs a minimum monthly parcel volume, so most small shops cannot integrate directly.

So the hard part is not the price. It is getting a valid PAXI point from the customer before the order is placed.

Option 1: flat rate plus a typed PAXI code (no plugin)

  1. Go to WooCommerce > Settings > Shipping, open your South Africa zone and add a Flat rate method.
  2. Name it something clear, such as "PAXI (collect at a PEP store)", and set the cost to your PAXI price.
  3. Ask the customer to type their PAXI point code in the order notes. Link to the PAXI map so they can look it up.

This costs nothing, but customers forget the code or type the wrong one, and you only find out when you are standing in PEP with the parcel. Order notes are also easy to miss when you pack.

Option 2: a required checkout field

Use a checkout field plugin to add a required "PAXI point code" field. It stops empty codes, but it cannot check that the code is real, and on the Checkout block (the default for new WooCommerce stores) many field plugins only work with the older shortcode checkout.

Option 3: a PAXI point picker on the checkout

Our free plugin, Skillmerc Shipping for The Courier Guy, Pudo and PAXI, adds a "PAXI (collect at a PEP store)" shipping method:

  • When the customer selects PAXI, a "Choose a PAXI point" button opens the official PAXI map inside the checkout.
  • The point they click (code, name and address) is filled in for them. The code must look like a real PAXI node code (a letter and digits, such as P1234), and the order cannot be placed without one.
  • The point is saved on the order and shown on the admin order screen, the order received page and the order emails, so you see it when you pack.
  • You set the Economy and Speed prices yourself (PAXI has no public rates API), plus an optional maximum cart weight and free shipping threshold.
  • It works on both the Checkout block and the classic checkout.

It does not book the parcel with PAXI. You still send it through your PAXI account or at a PEP store as usual. It is an independent plugin, not made by PAXI or Pepkor.

Which one to pick

  • A few PAXI orders a month: option 1 is fine.
  • PAXI is a main delivery option for you: a picker saves you from wrong or missing codes.
