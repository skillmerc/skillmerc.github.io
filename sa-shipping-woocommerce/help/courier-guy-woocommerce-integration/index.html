The Courier Guy WooCommerce integration: live rates at checkout

2 min readShipping for WooCommerce

Short answer: you need an account with The Courier Guy and an API key, and a shipping plugin that asks The Courier Guy's API for a rate for each cart and address. Our free plugin, Skillmerc Shipping for The Courier Guy, Pudo and PAXI, does this on the Checkout block and the classic checkout.

What you need

  • An account with The Courier Guy and an API key from Settings, API keys in the portal at portal.thecourierguy.co.za. To test first, a free sandbox account at sandbox.shiplogic.com gives you a sandbox key and test prices.
  • Your sender (collection) address.
  • A weight and dimensions on your products (Product data, Shipping). Products without them use the default parcel you set.

Set it up

  1. Install and activate the plugin. WooCommerce must be active.
  2. Go to WooCommerce, Settings, Shipping, open your South Africa zone and add "The Courier Guy (door to door)".
  3. Edit the method. Set "Environment" to Sandbox or Live to match your key, and paste the key into "API key".
  4. Fill in the sender company, street address, suburb, city, postal code and province.
  5. Check the default parcel weight and size, and set a "Fallback rate (R)". The fallback shows if the rates call fails, times out or returns nothing, so a rates outage does not leave customers with no shipping option.
  6. Optional: add a markup in rand or percent, or limit "Service levels to show" to codes such as ECO.
  7. Add a product to the cart, enter a South African address and check the rates at checkout.

Each service level on your account shows as its own option. Rates are cached for 10 minutes per address and parcel.

What it does not do

The free plugin quotes rates. It does not book collections, print waybills or send tracking numbers: book in your The Courier Guy portal, or use the paid Pro add-on, which books The Courier Guy shipments from the order screen.

If customers see no rate, see The Courier Guy not showing at checkout. If you use The Courier Guy's own plugin, read what The Courier Guy has said about retiring it.
