Pudo API key: where to get it and how to use it in WooCommerce

2 min readShipping for WooCommerce

Short answer: sign in to the Pudo customer portal at customer.pudo.co.za and create a live key under Settings, API keys. For testing, sign up for a free sandbox at sandbox.pudo.co.za and create a sandbox key there. Pudo is now The Courier Guy Locker.

What the key is used for

  • Rates need the key. Each quote asks Pudo for the price from your sender address to the locker the customer picked.
  • The locker list does not. Our plugin downloads Pudo's public locker list, which needs no key. If the public list cannot be loaded, it asks for the list with your key instead.

A sandbox key only works in sandbox and a live key only works live. Make sure the plugin's mode matches the key.

Where to paste it in WooCommerce

With our free plugin, Skillmerc Shipping for The Courier Guy, Pudo and PAXI:

  1. Go to WooCommerce, Settings, Shipping and open your South Africa zone.
  2. Add or edit "Pudo locker".
  3. Set "Environment" to Sandbox (test account) or Live, to match the key.
  4. Paste the key into "API key", fill in your sender address and save.
  5. Add a product with a weight and size to the cart and go to checkout. A locker list appears under the shipping options, lockers in the customer's postal code, town and province first, with a search box.

The plugin quotes the smallest locker box, XS to XL, that fits the cart. If nothing fits the largest box, Pudo is not offered for that cart. The order cannot be placed until a locker is chosen.

If Pudo does not show at checkout, see Pudo locker option not showing. For how Pudo prices parcels, see Pudo locker shipping in WooCommerce.
