YouTube channel research desk: a free n8n workflow for Google Sheets

8 min readYouTube Transcript Scraper

This is for people who follow more YouTube channels than they can watch: researchers, marketers, students and creators who keep an eye on other channels. You list the channels once. Every morning the workflow saves the transcript of each new video to a Google Sheet, so you can read, search and quote what was said without watching it all.

What it does

The workflow runs every morning at 07:00 in n8n, or when you click Execute workflow. It sends all your channels, playlists and videos to the YouTube Transcript Scraper on Apify in one run, with "only new videos" on, so each video comes back once. Each new video becomes one row in the Videos tab: title, channel, date, views, likes, chapters and the transcript with a time mark about every minute. Videos that cannot be read go to a Failed tab with the reason. Every run adds a line to a Run log. If you switch it on, a chat model writes a 5-line summary of each video with key points that link into the video near that moment. You get one digest by email when there are new videos, and a chat answers questions from the transcripts in your sheet.

Get the workflow

Download the workflow (JSON, 51 KB)

In n8n, open a new workflow, click the three dots at the top right and choose Import from File, or paste the file's contents onto the canvas. The file holds no credentials, no sheet ids, no tokens and no saved test data. You add your own in the steps below.

Set it up in 5 steps

The note on the canvas lists the same steps.

  1. Make a Google Sheet with four tabs: Sources, Videos, Failed and Run log. In Sources, type Link and Label in the first row, then paste the channels you follow.
  2. Create a free Apify account and copy your API token. In n8n, add a Header Auth credential. The name is Authorization. The value is the word Bearer, a space, and your token. Pick it in the four Apify nodes.
  3. Connect Google Sheets and Gmail with Sign in with Google. If a Sheets node then shows Map Each Column Manually, switch it back to Map Automatically.
  4. Open Settings and paste your sheet link and your email. This is also where you set the language, how many videos per channel, and a spend cap for each run.
  5. Click Execute workflow. It starts one Apify run for all your sources and checks on it every thirty seconds until it is done. Check the tabs, then activate the workflow so it runs every morning.

What each section does

The canvas has seven sections, each with its own note.

  • 1. Start and settings. Starts daily at 07:00, by hand, from the form or from the chat. Settings holds every value you change.
  • 2. Add a source from the form. Checks that a link is a YouTube channel, playlist or video and adds it to the Sources tab once. The next run picks it up.
  • 3. Collect new transcripts. One Apify run for all sources, capped by maxItemsPerRun and maxCostPerRunUsd. Only new videos come back. Type no in an Active column to pause a source.
  • 4. Understand (optional). Runs only when useAI is true. A long transcript is cut to evenly spaced one-minute parts that fit maxAiCharacters (40,000 by default), so the summary covers the whole video. Each video gets a 5-line summary, 3 to 6 key points with links, topics and a "worth watching" note.
  • 5. Store in Google Sheets. Videos and Failed are updated by Video ID, so running twice never adds a duplicate. Every run, failed or not, adds one Run log row with the counts, the charge Apify reports and a link to the Apify run.
  • 6. Tell. One message per run with the new videos. Nothing is sent when nothing is new. Gmail is on; Slack and Discord nodes are ready to switch on instead.
  • 7. Ask your channels. Open the chat and ask a question. It searches the transcripts in your sheet by keywords, with no vector database, and answers with links to the moment it was said. If the videos do not cover something, it says so.

What it costs

There are two costs, and both are usually small.

Transcripts (Apify). The YouTube Transcript Scraper charges USD 1.00 per 1,000 transcripts on Apify's free plan, and less on paid plans (USD 0.90, 0.80 and 0.70). There is also a start fee of up to USD 0.00005 per run. Failed videos and videos already delivered are free. The spend cap in Settings (maxCostPerRunUsd, USD 0.20 by default) caps what any one run can be charged.

Summaries and chat (your model account). The AI step is off until you set useAI to true. It then runs on your own model account (OpenAI in the template; you can swap that one node for Anthropic or Gemini) and your provider bills you for it.

Worked example: 20 channels, about 3 new videos a day in total.

  • Transcripts: 3 a day for 30 days is 90 transcripts. 90 x USD 0.001 = USD 0.09 a month on Apify's free plan.
  • Start fees: one run a day, 30 x USD 0.00005 = USD 0.0015 a month.
  • Apify total: about USD 0.09 a month.
  • AI summaries, as an estimate: the three transcripts in our test were about 10,000 to 38,000 characters long. At a rough 4 characters per token, that is about 2,500 to 9,500 tokens of input per video, plus a few hundred tokens for the reply. The workflow never sends more than 40,000 characters (about 10,000 tokens) per video. For 90 videos a month, plan on roughly 0.2 to 0.9 million input tokens and under 0.1 million output tokens. Multiply by your provider's price per million tokens.
  • Chat, as measured once: one chat answer in our test used 3,262 tokens in total.

Prices can change. The actor's page on Apify is the source for the current price.

Honest limits

  • Videos without captions fail. The actor reads YouTube's caption tracks. It does not turn audio into text. A video with no captions goes to the Failed tab with the reason no_captions, and it is not charged. Members-only, age-restricted and private videos are not read either, because the actor never logs in.
  • A chat link can open up to a minute early. For each match, the chat sends the model that minute of transcript and the next one, so its links point to the start of those two minutes. In our test with Gemini, the chat answered 4 of 4 questions right after a fix to its search. That is one small test, not an accuracy figure.
  • Google Sheets has size limits. A cell holds at most 50,000 characters, so the workflow cuts a longer transcript at 49,000 characters and flags it. That is very roughly an hour of talk. The chat can only search what is in the sheet. A Google Sheet also has a limit of 10 million cells per file, and a sheet full of long transcripts gets slow long before that. Start a new sheet when it does.
  • The daily run needs n8n to be running. On n8n Cloud that is handled for you. If you host n8n yourself, the 07:00 run only happens while your n8n is on.
  • Channel links read the Videos tab. Shorts and live streams on a channel's other tabs are not included.

Troubleshooting

The Run log shows NOT STARTED. The Apify call failed before a run began. With a wrong token the row says "Apify call failed: 401 User was not found or authentication token is not valid". Open the Header Auth credential: the name must be Authorization, and the value must be the word Bearer, a space, then your Apify token. Make sure the same credential is picked in all four Apify nodes.

A video is in the Failed tab with no_captions. The video has no caption track, not even an automatic one. There is nothing to fix and you were not charged. Other reasons you may see: live_now and upcoming (try after the stream has aired), stream_processing (try in a few hours), members_only, age_restricted, private and unavailable (these will not work), and other (often works later). Failed videos are tried again on the next run.

A Sheets node shows Map Each Column Manually and rows come out empty or wrong. n8n sometimes switches a Google Sheets node to manual mapping when you connect a new credential. Open that node and set it back to Map Automatically. This is setup step 3.

The run worked but no new rows appeared. "Only new videos" is on, so a video delivered once does not come back. If you want to start again, put a new value in stateKey in Settings.

No digest arrived. Nothing is sent when there are no new videos. Check the Run log for the day's counts.

FAQ

Do I need to know how to code?

No. You import the file, connect three accounts and paste two values into Settings. The Code nodes are already written.

Do I need a YouTube API key?

No. The Apify actor reads public videos without a YouTube API key and without logging in.

Can I use it without the AI part?

Yes. The AI step is off by default (useAI is false). Without it you still get the transcripts, the Failed tab, the Run log and the digest. The chat is the one part that needs a model credential.

Which languages work?

Set the language in Settings. If a video has captions in that language you get them. If not, you get the video's own language, then English, and the row shows which language you got. The actor does not machine-translate.

Can I add a channel without opening the sheet?

Yes. The workflow has a form that checks the link and adds it to the Sources tab. The next run picks it up.
