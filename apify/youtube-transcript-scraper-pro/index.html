YouTube Transcript & Subtitles Scraper - Bulk & Channels

Runs on ApifyPay per result

Get YouTube transcripts and subtitles as clean text with timestamps, from videos, Shorts, playlists or whole channels. Any language. $2 per 1,000, and videos without captions are never charged.

Open in Apify StoreExample: YouTube Channel Transcripts to Plain Text

Turn YouTube videos into text. Paste video, Shorts, playlist or channel URLs and get back one JSON row per video with the full transcript, timestamped segments and video details. Works with any caption language, manual or auto-generated.

$2 per 1,000 transcripts. Videos that have no captions, or that fail, are never charged.

What you get

For each video:

  • The full transcript as one clean string, ready for an LLM, a search index or a document
  • Timestamped segments (start, duration, text) for subtitles, quotes and chapter work
  • Title, channel, channel ID, duration and view count
  • Which caption language you got, whether it was auto-generated, and every language the video offers

Quick start

  1. Paste one or more YouTube links into Video URLs or IDs.
  2. Set Language to the caption language you want (for example en, es, de, pt, ko).
  3. Click Start. Download the results as JSON, CSV, Excel or HTML, or read them through the Apify API.

Input example

{
  "videoUrls": [
    "https://www.youtube.com/watch?v=dQw4w9WgXcQ",
    "https://youtu.be/jNQXAC9IVRw",
    "https://www.youtube.com/shorts/VIDEO_ID",
    "https://www.youtube.com/playlist?list=PLAYLIST_ID",
    "https://www.youtube.com/@3blue1brown"
  ],
  "language": "en",
  "preferManual": true,
  "includeTimestamps": true,
  "plainText": true,
  "expandPlaylists": true,
  "maxItems": 200
}

Accepted links: watch?v=, youtu.be/, /shorts/, /embed/, /live/ and bare 11-character video IDs. Playlist links (?list=) and channel links (/@handle or /channel/UC...) are expanded into their videos when Expand Playlists is on.

Input options

Field Default What it does

includeTimestamps true Return the timestamped segments list
plainText true Return the whole transcript as one string in transcript_text
expandPlaylists false Expand playlist and channel links into individual videos

Pricing

You pay $2.00 per 1,000 transcripts delivered, which is $0.002 per video. There is also a start fee of $0.00005 per GB of run memory, which is a fraction of a cent per run.

You are only charged for rows in the results dataset. Videos that can't be transcribed (no captions, private, deleted, age-restricted, or blocked by YouTube after every retry) are never written there. Instead they are listed with the reason in the run's OUTPUT record and in a separate failed-videos dataset, at no charge.

Use cases

  • LLM and RAG pipelines. Feed clean transcript text into ChatGPT, Claude or a vector database to summarise videos or answer questions about them.
  • Content repurposing. Turn videos and podcasts into blog posts, newsletters, show notes and social posts.
  • Research. Pull every talk from a channel or playlist and search, quote or analyse what was said.
  • Subtitles and quotes. Use the timestamped segments to find the exact moment something was said.
  • SEO and competitor research. See what topics and keywords other channels cover.

How it works

Transcripts come from YouTube's own caption tracks through its mobile player API, not from scraping the web page. YouTube often blocks cloud servers, so when a request is refused the actor retries that video through fresh proxy IPs (datacenter first, then residential). Retries are included in the price.

In tests on 27 September 2026 it delivered 30 of 33 random videos across 7 languages. The 3 misses had no captions at all. A 3.5-hour podcast came back at 29,466 words, and transcripts matched YouTube's own transcript view at about 97%.

Limitations

  • Videos with no captions at all can't be transcribed. This is common for music videos and sports highlights. They are reported free of charge.
  • If the language you ask for isn't available, you get the best track the video has (manual first, then auto-generated). The language field tells you which one you got.
  • Channel links return the channel's latest uploads from its Videos tab.
  • A link that contains both a video and a playlist (watch?v=...&list=...) is treated as that single video. Use the playlist?list= link to get the whole playlist.
